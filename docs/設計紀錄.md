## 2. 所有遊戲的共同設計原則（Sandy 定的）

好玩的遊戲 = 玩家一直做決定，每個決定都有代價。不是換了外皮的選擇題。

1. **時間壓力**：時間會走，慢會有後果。
2. **取捨、顧此失彼**：多個角色同時需要你。
3. **血量數值**：玩家自己也有體力／電量，要花時間回血。
4. **角色有個性**：同一招不是對每個人都有效。
5. **動手做**：拖曳、按住、連點；手機觸控和電腦滑鼠都要能用（pointer events）。不要只等倒數。
6. **探索和驚喜**：藏東西、隨機事件、彩蛋角色。
7. **結尾照鏡子**：用玩家這局的真實數字，說出他做決定的習慣、代價、一個小習慣建議。輕鬆好笑，不說教。這是情緒覺察、為自己負責。
8. **獎勵要吸引人**：貼紙、徽章、圖鑑、稱號、最佳紀錄。**全失敗也要有鼓勵**（例如「第一天上工」徽章、鼓勵稱號），接著導 CTA 或再玩一次。
9. **一開始就讓玩家看到目標**（「今天的任務」頁），不要藏在結果頁最下面。
10. **數值變化要看得懂**：變化當下寫出原因（「−4 小寶在哭」），快出事前先預告。
11. **新手先玩簡化版**，好玩、想收集徽章，再開放完整版。
12. **結尾只有一個主要 CTA**。
13. 改版前留舊版，方便比較。

## 3. 三明治鎮（/town）

- 一天 08:00→17:00。居民有緊繃值，滿了被聳肩怪抓走（卡住＝失敗）。小宇 12:00、阿傑 12:40 才出現。
- 玩家有體力；噴水池、長椅回體力（花時間）。
- 每個動作兩關：**拉到位**（拖黃點到綠圈，小人跟著變姿勢）＋**穩住**（吸氣按住、吐氣放開，指針留在綠色；吸 4 秒吐 5 秒；第一次先「試一次」不計分）。
- 先聊聊／直接教，依居民個性。
- 聳肩怪在地圖亂走，**連點 5 下嚇跑**（有瑜伽繩 3 下），第一次靠近會提示。
- 驚喜：番茄車翻了、午休鐘、下雨、外送爆量、起司先生隨機出現、按摩券、瑜伽磚。
- 救回 3 位以上解鎖序列圖卡；地圖、任務頁、結果頁都顯示進度。
- 結果頁：救回幾位、稱號（每個救回數有好幾個，0 位也鼓勵）、沒救回的部位、教學風格反思（救火隊長、慢工出細活、硬撐型、路痴型、順路型、全場跑透透）、2 個依這局狀況給的小提示。
- 序列區塊：不寫日期，不寫「這週／下週」。寫「卡住的是{部位}？這套序列剛好練得到。」
- CTA：「追蹤 @sandywich.su，跟著練」＋電腦版 QR code＋「存成限動圖，分享並標記 @sandywich.su」（1080×1920 戰績圖）。
- 徽章 9 個：第一天上工、全員救回、磚家、起司先生、零失敗、體力管理大師、神速、完美 5 次、越挫越勇。
- 貼紙簿順序：稱號 → 貼紙（三明治）→ 徽章 → 怪物圖鑑 → 背包，字體統一。
- 存檔：`sandywich.player`，`v: 3`，舊版會自動轉換。
- 調難度：zone json 的 `rules.hold`、各居民 `rate`、`rules.lessonMin`。

## 4. 我熱愛當媽🙃（/mom）

- 原名「兩寶媽的一天」，靈感是 drcharming.net/game「我熱愛值班」。
- **快速版**（預設）：晚上 18:00–21:30，約 3 分鐘，只看精力、耐心、肚子。
- **完整的一天**：06:30–23:00，鎖住；快速版收集 3 個徽章解鎖，或輸入解鎖碼（`UNLOCK={badges:3, code:'', lineUrl:''}`）。以後可改成「加 LINE 好友拿解鎖碼」。
- 數值變化旁邊寫原因；「現在最急」按鈕；第一次玩有 3 個提示。
- 爆炸預告：耐心 < 30 → 紅框閃、冒煙、「💣 約 X 分鐘後爆炸」、三個急救按鈕。爆炸：BOOM💥、震動、媽媽變火山、小孩嚇跑。
- 小遊戲：煎蛋、換衣服、洗澡搓髒點、跟著圈圈呼吸。
- 結尾「今天的你，是哪一種媽媽？」：燃燒自己型、火山爆發型、救火隊長型、全部都要型、懂得充電型、放生大師型。累倒或爆炸 → 建議照顧自己。
- 待辦：解鎖門檻可能太簡單（考慮 4–5 個）；快速版底部說明還寫著公司／健身房要改。

## 5. 心情除錯所（/mood）

- 資訊課 SEL 遊戲。下課 10 分鐘，5 位同學溫度上升，到 100 當機還會傳染；玩家有電量。
- 每位同學個性不同、情緒表現不同。流程：開口方式 → 從線索選最貼近的情緒詞 → 用工具（要先去福利社／保健室／電腦教室拿）→ 動手小遊戲（拆任務、事實與猜測、5-4-3-2-1、我訊息積木、呼吸）。
- 驚喜：群組訊息爆炸、王老師 Error 404：耐心 not found、隱藏貼紙。
- 結尾：今日系統報告、除錯風格反思、情緒字典、`console.log(今天的我)`、「找導師或輔導老師聊聊，也是一種除錯」。
- 給老師的 Gemini 版 prompt 分 3 段，寫在 Claude Doc「用 Claude 做教學小遊戲：給老師的步驟」。

## 7. IG 試行上線（LINE 還沒開）

IG 能放「可以點的連結」的地方：

| 位置 | 可以點嗎 | 怎麼用 |
|---|---|---|
| 個人簡介連結 | ✅ | 放遊戲網址（可放多個連結） |
| 限時動態「連結」貼紙 | ✅ | 每次發遊戲相關限動都貼；存進精選動態「遊戲」 |
| 私訊 | ✅ | 留言關鍵字後私訊網址（手動或自動回覆工具） |
| Reel／貼文文案 | ❌ | 寫「網址在主頁」或「留言『玩』傳給你」 |
| 留言 | ❌ | 置頂留言寫「點主頁連結」 |
| Reel 內可點連結 | 需付費（Meta Verified 商業方案或下廣告） | 先不用 |

讓 IG 推播更多的玩家行動：分享戰績限動並標記 @sandywich.su（最有效）、存檔（收藏 Reel）、留言救回幾位、傳給朋友。

## 8. 以後的 LINE 流程（準備好再做）

- 登入方式選 LINE（IG 沒有開放網站登入；Google 只拿得到 Email；Email 註冊太長）。
- **包裝成玩家的好處**，不要說「請登入」：
  - 「換手機、換電腦也能接著玩」
  - 「儲存你的進度，下次不用重來」
  - 「把你的寶物（貼紙、徽章、背包）存起來」
  - 「領你的專屬序列圖卡」「下一區開放第一個通知你」「把你的煩惱變成鎮上居民」
- **時機**：最有成就感的時候（解鎖圖卡那一刻、想進第二區時），不要一開始就擋。
- **流程**：
  1. 結果頁「用 LINE 一鍵存起來」＋小字「不會幫你發文，不會看你的聊天」。
  2. LINE 同意畫面附「加入 Sandywich Yoga 好友」（官方帳號要跟 LINE Login 頻道綁定），預設勾選。
  3. 回到遊戲「歡迎，○○！進度已存好」。加好友的人收到歡迎訊息＋圖卡；沒加的人在遊戲裡看到加好友按鈕。
  4. 加好友才拿得到解鎖碼（我熱愛當媽完整版、第二區）。
  5. 每月新區開放發一則通知就好。
- 登入≠加好友：登入只知道他是誰、存進度；加官方帳號好友才能傳訊息給他。
- 技術：Vercel 後台小程式＋資料庫（Supabase）。LINE 和資料庫的金鑰由 Sandy 自己貼進 Vercel → Settings → Environment Variables，不要貼在對話裡。
- 能知道：LINE 名字、大頭貼、有沒有加好友、遊戲裡的進度、傳給官方帳號的訊息。不能知道：他的聊天、好友、電話。

## 9. 投稿居民（以後的參與感）

靈感：宅女小紅 Podcast 的「筆友青紅燈」（讀聽眾投稿的感情、婚姻故事來聊）、飛碟電台「青春點點點」（馬克信箱等讀聽眾來信、call-in 的單元）。
做法：玩家投稿肩頸／身體的煩惱和暱稱 → 每月公開抽 3 則 → 變成下一區的居民，並拍成一支「三明治鎮信箱」Reel 唸投稿、配上動作。需要投稿表單（先用 Google 表單或 IG 限動提問貼紙）。

**2026-10-28 Sandy 定的方向**：投稿主題是「心裡卡卡的事」（心理覺察、生活裡的小煩惱），不是身體症狀。不回答醫療、復健、物理治療問題，投稿頁要寫清楚；這類投稿不選用。沒有標準答案、有題材可以拍 Reel。投稿完一樣有 CTA：追蹤 IG（以後加 LINE）。若收到自傷或危機內容，不選用、不公開，私下回覆並提供 1925 安心專線。

## 11. 自動回覆（Sandy 不要手動私訊）

- IG：Meta Business Suite（電腦版）→ 收件匣 → 自動化。可設「留言自動私訊」與「自訂關鍵字」（私訊含關鍵字就回網址）。需要專業帳號。若帳號沒有這個功能，再用第三方工具（ManyChat 等，免費版人數有限）。
- LINE 官方帳號：管理後台 → 自動回應訊息 → 新增 → 勾「使用關鍵字」（例：玩、遊戲）→ 回覆遊戲網址；另設「加入好友的歡迎訊息」。
